Editorial Overview

Wordtune, developed by AI21 Labs, is an interactive reading and writing companion tool integrating directly into browser functionality and word processors. Its core function is a sentence-by-sentence rewriting engine designed to alter the tone, length, and clarity of textual input using proprietary large language models. Rather than generating long-form content from a blank page independently, it focuses on the active revision and refinement of user-generated drafts. Its primary capability lies in its granular editorial control. A user highlights a specific sentence within their document, and the system generates multiple distinct variations. The user can explicitly direct the engine to produce a more formal corporate tone, a casual conversational style, or condense the content for brevity. An integrated reading companion also processes complex, lengthy articles, generating summarized analytical sidebars to expedite data consumption. It is predominantly utilized by professional communicators, non-native English speakers attempting to resolve grammatical friction, academic researchers streamlining dense writing, and marketing personnel executing rapid copy revisions.

How it works

An employee drafts an email to their executive team, but the phrasing feels overly aggressive: "We need to fix the database immediately because the current state is bad." The employee highlights the sentence using the Wordtune Chrome extension. They select the "Formal" tuning option. The system processes the text and instantly displays five variations. The user selects: "It is imperative that we address the database infrastructure promptly, as the current state is sub-optimal." They click to replace the text seamlessly within their Gmail composition window.
