Editorial Overview

Frase (Frase.io) is an AI-powered SEO and content optimization platform designed specifically for content marketers and SEO agencies. Unlike general AI writers that simply generate text from a prompt, Frase is engineered to reverse-engineer Google search results, ensuring the content written is mathematically optimized to rank for specific keywords. It acts as a bridge between SEO research and content creation. It analyzes the top 20 Google results for any given search query to extract the exact headings, keyword frequencies, and topics covered by competitors. It then provides a real-time scoring editor that grades a writer's draft against those metrics. With the integration of generative AI, Frase allows users to not only outline and optimize articles but to generate the actual paragraphs directly within the optimization editor, creating a highly streamlined SEO content factory workflow.

How it works

A user enters a target keyword (e.g., "Best CRM for real estate"). Frase scrapes the top Google results and generates a Research panel detailing the average word count, headings used, and overlapping topics. The user utilizes AI to auto-generate a comprehensive article outline based on competitor headings. They then write (or use the AI writer to generate) the content in the central editor. A dynamic score from 0-100 updates in real-time as the text incorporates semantic keywords suggested by the platform.
