Editorial Overview

Adobe Firefly is Adobe's suite of generative AI models integrated into the Adobe Creative Cloud ecosystem. Launched in 2023, Firefly provides text-to-image generation, generative fill, text effects, and other AI-powered creative tools directly inside Adobe Photoshop, Illustrator, and Adobe Express. A key differentiator for Firefly is Adobe's commitment to training the model on licensed content, including Adobe Stock images, to provide clearer commercial usage rights compared to models trained on broadly scraped web data. This positions it as suitable for professional commercial creative work. Firefly is primarily targeted at existing Adobe Creative Cloud users who want to add AI image generation and editing capabilities to their established design workflows, rather than standalone AI image tool adopters.

How it works

In Photoshop, users select an area of an image and use Generative Fill to describe what should appear in that area — the AI generates multiple options that blend with the existing image context. Generative Expand allows users to extend the canvas and fill the new area with AI-generated content matching the original. In Illustrator, users generate vectors from text prompts. Adobe Express users access a simplified interface for generating images from text. All features are accessible via the Creative Cloud applications without a separate login.
