SiteGPT

SiteGPT creates a website support chatbot from supplied material. Plans limit source capacity and message usage, and available message volume depends on the selected model. The vendor offers a seven-day trial with a credit card, but explicitly states there is no free plan. API access and the iOS inbox are plan-dependent, so compare the relevant tier rather than just the entry price.
