Recraft

Recraft offers image and vector generation and editing, with programmatic access through its API. The free plan's outputs are public and not licensed for commercial use under the vendor's stated terms. Paid-plan output rights differ. Subscription credits and API units are purchased separately, so a creator subscription should not be treated as an API allowance.
