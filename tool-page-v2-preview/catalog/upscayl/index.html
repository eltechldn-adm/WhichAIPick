Upscayl

Upscayl Desktop enlarges low-resolution images on a local computer. Official downloads support Windows, macOS and Linux, and the project publishes its source under AGPL-3.0. Its repository calls for a Vulkan-compatible GPU and cautions that the tool is not a fix for out-of-focus images. This listing's free-software classification applies to desktop downloads, not every distribution or cloud offering.
