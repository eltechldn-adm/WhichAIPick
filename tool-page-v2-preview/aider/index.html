Aider

Aider is a terminal-based coding assistant that edits a codebase using a selected language model. It integrates with Git and can run linting or tests around changes. Installation is documented for macOS, Linux and Windows. The Apache-2.0 client can use local or cloud models, so software availability should be distinguished from model-provider charges and local computing requirements.
