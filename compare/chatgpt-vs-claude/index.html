ChatGPT vs Claude: Free vs Paid, Coding, Writing and Pricing Guide

Compare ChatGPT and Claude across free and paid plans ($20/mo), writing, coding (Codex vs Claude Code, Artifacts, code blocks), document analysis, privacy, and APIs.

Research checked: 2026-11-08

Quick Answer

ChatGPT and Claude both offer free tiers, $20/month flagship personal plans ($20 USD / £20 GBP incl. VAT in UK for ChatGPT Plus; $20 USD monthly or $17 USD/mo billed annually at $200 for Claude Pro), high-capacity plans ($200/mo ChatGPT Pro; $100/mo Claude Max and $200/mo Claude Ultra/Max), team/enterprise workspaces (starting at 2 seats), and token-billed developer APIs. Neither assistant is a universal winner: ChatGPT is an all-in-one multimodal workspace with live web search, Advanced Voice Mode, native ChatGPT Images generation, and sandboxed Python data analysis, whereas Claude specialises in natural long-form writing, model-dependent context windows up to 1M tokens, live UI rendering in Artifacts, and terminal-based coding with Claude Code.

  • → Choose ChatGPT if you want one multimodal workspace combining live web search, Advanced Voice Mode, native ChatGPT Images creation, sandboxed Python spreadsheet analysis, OpenAI Codex for terminal/IDE coding, and interactive writing and code blocks. (Editorial recommendation · Sourced)
  • → Choose Claude if your priority is nuanced long-form writing, analysing lengthy contracts or codebases in a model-dependent context window of up to 1M tokens, previewing interactive UI components in Artifacts, or running agentic terminal workflows with Claude Code. (Editorial recommendation · Sourced)
  • → Personal plans start at $0 (Free) and $20 USD/mo on flagship tiers: ChatGPT Plus costs $20 USD/mo (£20 GBP/mo incl. VAT on UK web checkout; ChatGPT Go is $8 USD/mo where available), while Claude Pro costs $20 USD/mo monthly or $17 USD/mo billed annually ($200 upfront, plus applicable local tax/VAT). High-capacity tiers scale to Claude Max ($100/mo 5x) and Ultra/Max ($200/mo) and ChatGPT Pro ($200/mo). (Official source fact)
  • → Apps, business workspaces, and APIs are separate products: ChatGPT Business Standard ($20 USD/user/mo billed annually or $25 monthly, minimum 2 seats) and Claude Team (minimum 2 seats, 2-150 total; Standard seat at $20 USD/seat/mo annual or $25 monthly and Premium seat at $100 annual or $125 monthly, with both seat types including Claude Code) do not train models on company data by default, and developer APIs (OpenAI Platform API and Anthropic API) are billed per token. (Official source fact)

Key Differences

Writing, Editing & Research Workflows

Claude is widely used for structured long-form drafting, custom writing Styles, and multi-document synthesis alongside web search and Research mode. ChatGPT pairs interactive inline writing blocks and side-by-side editing with ChatGPT Search and multi-step Deep Research reports.

Coding & Software Development (OpenAI Codex vs Claude Code & Artifacts)

Both platforms offer terminal coding agents and in-app code workspaces: Claude includes Claude Code (across Pro, Max, Ultra, Team Standard & Premium seats, Enterprise, and API) alongside live browser Artifacts for React/HTML previews. OpenAI provides Codex (including the open-source Codex CLI for terminal repository coding, IDE extensions for VS Code/Cursor, and desktop integration) authenticated with ChatGPT subscription accounts (Plus, Pro, Business, Enterprise) or API keys, alongside interactive code blocks and sandboxed Python data execution.

Files, Context Windows & Document Analysis

Claude supports model-dependent context windows up to 1M tokens across Free, Pro, Max, Ultra, Team, Enterprise, and API tiers (with 1M tokens on current flagship models and 200K tokens on select variants) for analysing full contracts, financial filings, and multi-file Projects. ChatGPT combines persistent Projects with Advanced Data Analysis, executing Python directly on uploaded CSV and Excel files to clean data and plot charts.

Multimodal Capabilities (Voice & Image Generation)

ChatGPT is a broader multimodal generation suite featuring Advanced Voice Mode for spoken dialogue and native ChatGPT Images creation and editing. Claude analyses uploaded images, charts, and PDFs and renders interactive SVG/HTML diagrams via Artifacts, but does not generate photorealistic raster images.

Pricing, Plan Tiers & Currency Billing (USD & GBP)

Both start at $0 on Free and $20 USD/mo on flagship monthly plans. OpenAI offers ChatGPT Go ($8 USD/mo where available), ChatGPT Plus ($20 USD/mo; £20 GBP/mo incl. VAT in UK), and ChatGPT Pro ($200 USD/mo; £200 GBP/mo). Anthropic offers an annual discount on Claude Pro ($17 USD/mo billed annually at $200, or $20/mo monthly) and two high-capacity tiers: Claude Max 5x ($100 USD/mo) and Max 20x ($200 USD/mo).

Privacy, Data Handling & Model Training Defaults

On commercial and API tiers (ChatGPT Business, ChatGPT Enterprise, OpenAI API, Claude Team, Claude Enterprise, and Anthropic API), neither provider trains generative models on customer data by default. On consumer plans (ChatGPT Free/Go/Plus/Pro and Claude Free/Pro/Max), chats and coding sessions may be used for model improvement unless you opt out in your privacy settings.

Strengths & Limitations

ChatGPT

Key Strengths

  • All-in-one multimodal workspace combining ChatGPT Search, Advanced Voice Mode, and native ChatGPT Images generation (Official source fact)
  • Sandboxed Python execution (Advanced Data Analysis) for cleaning spreadsheets, running scripts, and exporting files (Official source fact)
  • OpenAI Codex CLI and IDE extensions for repository coding, interactive in-chat writing and code blocks, persistent Projects, and Custom GPTs (Official source fact)
  • Local UK GBP billing (£20/mo incl. VAT on web checkout) alongside USD pricing and an $8/mo Go entry tier where available (Official source fact)

Notable Limitations

  • Does not offer an annual billing discount on ChatGPT Plus ($20/mo monthly only) (Official source fact)
  • Consumer plans (Free, Go, Plus, Pro) do not include OpenAI Platform API token credits (Official source fact)
  • Default writing tone can require more prompt steering than Claude for long-form editorial prose (Editorial synthesis)

Claude

Key Strengths

  • Model-dependent context windows up to 1M tokens across supported Claude models for analysing full contracts, books, and multi-file repositories (Official source fact)
  • Artifacts workspace for live rendering of React components, HTML/CSS prototypes, SVG graphics, and diagrams (Official source fact)
  • Claude Code terminal agent included across all paid plans: Claude Pro ($20/mo), Max ($100/mo), Ultra ($200/mo), Team (both Standard and 5x-usage Premium seats), and Enterprise (Official source fact)
  • Annual discount on Claude Pro ($17 USD/mo billed annually at $200) and flexible Max/Ultra tiers ($100/mo and $200/mo) (Official source fact)

Notable Limitations

  • No native photorealistic raster image generation (limited to visual input analysis and SVG/code diagrams) (Official source fact)
  • Rolling 5-hour session message caps can be reached quickly during heavy Opus or multi-file coding sessions on Free, Pro, and Standard Team seats (Official source fact)
  • Official pricing is published in USD (plus applicable local taxes/VAT at checkout) without a sub-$10 entry plan (Official source fact)

Decision Support

Choose ChatGPT if...

  • You want one subscription that includes native image generation (ChatGPT Images) and Advanced Voice Mode.
  • You regularly clean CSV/Excel spreadsheets and generate charts using sandboxed Python in Advanced Data Analysis.
  • You rely on live conversational web search combined with multi-step Deep Research reports.
  • You build reusable Custom GPTs and persistent Projects for recurring personal or team tasks.
  • You want fixed UK GBP web checkout (£20/mo incl. VAT on Plus) or an $8/mo entry tier (ChatGPT Go where available).

Choose Claude if...

  • Your primary work is long-form writing, editing, and synthesis where natural tone and custom Styles matter most.
  • You want live interactive previews of React, HTML/CSS, and diagrams in Artifacts or agentic terminal coding via Claude Code.
  • You analyse lengthy contracts, academic PDFs, or multi-file codebases using model-dependent context windows up to 1M tokens.
  • You want an annual discount on your individual plan ($17 USD/mo billed annually) or a $100/mo middle tier (Claude Max 5x).
  • Your engineering or knowledge team (2+ seats) wants mixed Standard ($20-$25/seat/mo) and Premium ($100-$125/seat/mo) seats with Claude Code and commercial data privacy.

Frequently Asked Questions

Is ChatGPT or Claude better on the free plan?

Both free plans ($0 / £0) handle everyday drafting, coding questions, and web search. Claude Free includes access to Claude Sonnet and Haiku (with model-dependent context windows up to 1M tokens), Artifacts previews, and up to 5 Projects, but enforces rolling 5-hour session caps and excludes Claude Opus and Claude Code. ChatGPT Free includes ChatGPT Search, standard voice, Custom GPT access, and limited ChatGPT Images generation.

How do ChatGPT Plus, ChatGPT Pro, Claude Pro, and Claude Max pricing compare?

On flagship monthly plans, both cost $20 USD/month: ChatGPT Plus is $20 USD/month (£20 GBP/month incl. VAT on UK web checkout), while Claude Pro is $20 USD/month monthly or $17 USD/month billed annually ($200 upfront, plus applicable local tax/VAT). For heavy individual users, Claude offers a $100 USD/month middle tier (Claude Max 5x) as well as a $200 USD/month tier (Claude Ultra/Max), whereas OpenAI steps from ChatGPT Plus ($20/mo) directly to ChatGPT Pro ($200 USD/mo; £200 GBP/mo).

Which is better for coding and software development: ChatGPT or Claude?

Both provide advanced coding workflows across consumer apps and developer tools. Claude features Artifacts for live React, HTML/CSS, and SVG rendering directly in the browser, plus Claude Code (included with Claude Pro, Max, Ultra, Team Standard and Premium seats, Enterprise, and API) for terminal-based agentic workflows across local repositories. ChatGPT provides OpenAI Codex (including the open-source Codex CLI for terminal repository coding and IDE extensions for VS Code and Cursor, authenticated with ChatGPT Plus, Pro, Business, Enterprise, or API keys), interactive in-chat code blocks with live previews, and a sandboxed Python environment for data science and file automation.

Which is better for long-form writing, editing, and document analysis?

Claude is frequently chosen for long-form writing and document review because its model-dependent context window (up to 1M tokens on current models, 200K on select variants) handles full contracts, transcripts, and book-length PDFs in a single prompt while maintaining a natural, low-fluff prose style. ChatGPT is strong when your writing workflow depends on interactive in-chat writing blocks with targeted paragraph feedback or combining uploaded documents with Python data tables.

How do ChatGPT Business and Claude Team compare for company use?

Both team plans require a minimum of 2 seats and start at $20 USD/seat/month billed annually or $25 USD/seat/month billed monthly (ChatGPT Business Standard for 2+ seats; Claude Team Standard for 2-150 seats). Both Standard and Premium seats on Claude Team include Claude Code, and organisations can mix Standard seats ($20-$25/mo) with high-capacity Premium seats ($100 USD/seat/mo annual or $125 monthly, providing 5x more usage for intensive coding), whereas ChatGPT Business focuses on shared Projects, Custom GPTs, and connectors.

How do ChatGPT and Claude handle data privacy and AI model training?

Both providers separate consumer and commercial data policies. On commercial workspaces and developer APIs (ChatGPT Business, ChatGPT Enterprise, OpenAI API, Claude Team, Claude Enterprise, and Anthropic API), neither company trains generative models on customer inputs or outputs by default. On consumer plans (ChatGPT Free/Go/Plus/Pro and Claude Free/Pro/Max/Ultra), conversations and coding sessions may be used for model training unless you turn off model improvement in your privacy settings.

Why does the catalogue table list API available as No for both ChatGPT and Claude?

WhichAIPick scopes the ChatGPT (/tools/chatgpt/) and Claude (/tools/claude/) catalogue records to the consumer assistant applications rather than their separate developer API platforms (OpenAI Platform API at /tools/openai-api/ and Anthropic's Claude Console API). Both companies offer full developer APIs billed per million tokens, and standard $20/month consumer subscriptions (ChatGPT Plus and Claude Pro) do not pay for general API calls—though Claude Max ($100/mo), Ultra ($200/mo), and Team plans include monthly Claude Platform API credit allotments under Anthropic's current terms.
