# PIPELINE ARCHITECTURE (Phase 9)

> **[IMPORTANT TEMPORARY SOURCE WARNING]**
> The current 902-tool catalogue in `data/tools.json` is a **TEMPORARY SOURCE**.
> A newly enriched spreadsheet is undergoing auditing and is intended to become the canonical source.
> Do NOT perform manual catalogue edits, URL remediation, or freshness updates until the new spreadsheet is approved and imported.

## Build Order

1. **`build:data`**: `node scripts/convert-xlsx-to-tools-json.mjs`
   Reads the canonical catalogue CSV and generates `data/tools.json`. (Currently frozen)
2. **`validate:data`**: `node scripts/validate-data.mjs`
   Performs critical integrity checks on `data/tools.json`. Fails if duplicate IDs or required fields are missing (Phase 4).
3. **`generate:pages`**: `node scripts/generate-static-pages.mjs`
   Consumes `data/tools.json` and generates all `/tools/[id]/index.html` static HTML files, applying header/footer configurations.
4. **`generate:seo`**: `node scripts/seo/generate-best-tools.mjs`, `generate-alternatives.mjs`, `generate-comparisons.mjs`, `generate-guides.mjs`
   Consumes `data/tools.json` to generate SEO hub and category pages (Phase 6).
5. **`inject:header` & `inject:footer`**: `node scripts/inject-header.mjs`, `node scripts/inject-footer.mjs`
   Injects the standard, globally-maintained navigation and footer HTML into all static pages generated by previous steps.
6. **`generate:sitemap`**: `node scripts/generate-sitemap.mjs`
   Scans the generated output directories and generates `sitemap.xml` (Phase 6).
7. **`generate:build-info`**: `node scripts/generate-build-info.mjs`
   Produces `build-info.json` to provide deployment observability (Phase 9).
8. **`validate:seo`**: `node scripts/seo-health-audit.mjs`
   Performs an internal QA check across all HTML files for missing metadata, duplicate H1 tags, or malformed JSON-LD (Phase 9).
9. **Cloudflare Deployment**: `wrangler pages deploy`
   Deploys the final static assets to the Cloudflare edge.

## File Editing Rules

### Canonical Inputs
These files **MUST** be manually edited and are considered the source of truth for the platform:
- `data/ai_tools_list.csv` / `data/ai_tools_list.xlsx`: The master canonical catalogue of tools.
- `data/monetisation.json`: The source of truth for global ads and affiliate parameters (Phase 7).
- `data/affiliate-links.json`: The source of truth for individual affiliate mappings (Phase 7).
- `data/categories.json`: Defines category taxonomy and SEO slugs.
- `data/seo/*`: Raw data mapping for best-tools, guides, alternatives, and SEO hubs.

### Generated Outputs
These files **MUST NEVER** be manually edited. Manual edits will be obliterated on the next `npm run build:cloudflare`:
- `data/tools.json`: Overwritten by `build:data`.
- `tools/[id]/index.html`: Overwritten by `generate:pages`.
- `best-ai-tools/*`, `alternatives/*`, `compare/*`, `guides/*`: Overwritten by `generate:seo`.
- `sitemap.xml`: Overwritten by `generate:sitemap`.
- `build-info.json`: Overwritten by `generate:build-info`.

Any data anomalies in `tools.json` or HTML files **MUST** be fixed by updating the Canonical Input files and running a full clean build.
