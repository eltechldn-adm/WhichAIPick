Capacities

Capacities is a networked note-taking and personal knowledge management (PKM) studio built around an object-oriented data architecture. Instead of treating notes as isolated text files or rigid hierarchical folders, Capacities models knowledge as distinct, interconnected real-world entities—such as people, projects, meetings, books, and ideas.

Each object type has custom properties, relational tags, and visual views (including graph, wall, list, and gallery layouts). Integrated AI capabilities allow users to summarize notes, query their knowledge base, create smart automations, and generate draft outlines directly within their interconnected digital workspace.

Best For

  • Knowledge workers, researchers, and writers who think in structured, interconnected entities rather than linear file folders
  • Professionals wanting a unified personal operating system linking daily journals, meeting notes, contacts, and project tasks
  • Thinkers looking for the visual relational power of Obsidian or Roam without the technical maintenance of local plugins and Markdown formatting

Not Ideal For

  • Users wanting a simple, barebones scratchpad for quick disposable checklists where object modeling adds unnecessary friction
  • Enterprises requiring strict local-only file storage under user-controlled encryption keys without cloud synchronization
  • Teams needing real-time simultaneous collaborative document editing in the style of Google Docs or Figma

How It Works

Capacities organizes information through a daily calendar note and a library of customizable object types. When capturing thoughts, users either record entries on their daily note or create a specific object (such as a 'Book', 'Meeting', or 'Concept'). Each object type features predefined metadata fields (such as dates, authors, tags, and status) alongside a rich-text canvas.

As notes are written, users link concepts using bi-directional @mentions and contextual blocks. Capacities automatically builds a dynamic knowledge graph showing how topics intersect. The built-in AI assistant can search across all linked objects, summarize historical notes, surface connections between disparate entries, and draft content using personal knowledge as context.

Key Features

Object-Oriented Architecture & PKM

  • Custom object definitions with specialized metadata properties, icons, and visual layouts
  • Bi-directional page and block linking with interactive interactive graph visualizations
  • Daily notes calendar hub automatically aggregating daily thoughts, media, and task completions
  • Flexible database views including grid walls, tables, kanban lists, and visual galleries

AI Studio & Ecosystem Integrations

  • Integrated conversational AI assistant with context-aware querying across private notes
  • Automated content capture via WhatsApp, Telegram, email forwarding, and web browser extensions
  • Native integrations with Readwise and Kindle for continuous book highlight synchronization
  • Full offline caching with end-to-end cloud synchronization across macOS, Windows, Linux, iOS, and Android

Strengths & Limitations

Strengths

  • Object-based mental model eliminates chaotic folder organization and creates structured, queryable knowledge
  • Generous free plan includes unlimited spaces, custom object types, and cross-device sync with zero feature paywalls
  • Clean, distraction-free aesthetic with visual galleries and graph views superior to traditional text-heavy PKM apps
  • Omni-channel capture via mobile messaging apps (WhatsApp, Telegram) enables instant mobile thought logging

Limitations

  • Initial learning curve requires users to intentionally design object schemas and relationship types
  • Real-time multi-user team collaboration is limited compared to dedicated enterprise workspaces like Notion
  • Advanced AI generation and semantic assistant features require an active paid Pro subscription
  • Total media upload storage on the free plan is capped at 5 GB initial quota (plus 100 MB monthly increment)

Pricing

Capacities operates on a freemium model with a free-forever foundational tier and optional paid tiers for AI and power features.

The Basic Plan ($0) is free forever and includes unlimited spaces, unlimited objects and blocks, unlimited custom object types, cross-platform synchronization (desktop and mobile), offline access, media capture via WhatsApp/Telegram, and 5 GB total media storage. Capacities Pro costs $9.99 per month (or approximately $7.99 to $8.33/month billed annually at $99.99/year) and adds the integrated AI assistant, interactive whiteboards, task management actions, smart queries, calendar integrations, version history, Readwise/Kindle sync, and unlimited media uploads. The Believer Plan costs $12.49 per month (or $120/year) and provides early beta access to new features as a community supporter tier.

How It Compares

Compared to Notion, Capacities uses an object-oriented architecture where an entity (e.g., a person or meeting) maintains its structural identity everywhere, whereas Notion relies on database rows nested within hierarchical pages. Compared to Obsidian, Capacities provides a polished, out-of-the-box cloud-synced environment without requiring community plugins, sync subscriptions, or Git setups, though Obsidian offers superior local Markdown privacy. Compared to Roam Research, Capacities replaces unstructured raw bullet-point outliners with visually rich cards, galleries, and structured object schemas at a lower subscription price.
